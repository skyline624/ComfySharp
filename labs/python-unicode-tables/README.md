# CPython 3.12.10 Unicode lowercase data

This directory contains a **static C-table extractor**, not a Python formatter or a source-output collector. It derives the full lowercase mappings and the Cased / Case_Ignorable properties from CPython's checked-in generated C arrays. It never imports the upstream Python generator, compiles or loads C, calls builtin casing, queries an operating-system Unicode database, or reads C# execution results.

The frozen reference is CPython tag `v3.12.10`, annotated tag object `f86fdcac4c104bb671f86eb77cf98a6aa764c04e`, resolving to commit **`0cc81280367df838c4b199f8f0378837165071c2`**. Resolution used the primary GitHub Git ref and tag-object APIs listed in [provenance.json](provenance.json). This documents tag resolution, not a locally verified signing-key chain.

All six original files are downloaded only into ignored preparation storage; no upstream source dump is distributed here. Their exact bytes and SHA-256 are in the provenance file:

- [Objects/unicodetype_db.h](https://github.com/python/cpython/blob/0cc81280367df838c4b199f8f0378837165071c2/Objects/unicodetype_db.h): generated type records, extended mappings and two-level index arrays.
- [Objects/unicodectype.c](https://github.com/python/cpython/blob/0cc81280367df838c4b199f8f0378837165071c2/Objects/unicodectype.c#L189): full lowercase expansion decoding and property masks.
- [Objects/unicodeobject.c](https://github.com/python/cpython/blob/0cc81280367df838c4b199f8f0378837165071c2/Objects/unicodeobject.c#L9509): original Final_Sigma context and lowercase dispatch.
- [Tools/unicode/makeunicodedata.py](https://github.com/python/cpython/blob/0cc81280367df838c4b199f8f0378837165071c2/Tools/unicode/makeunicodedata.py#L47): declares Unicode **15.0.0**; this file is read as text and is never imported.
- The same commit's LICENSE and Doc/license.rst record licensing provenance. The complete LICENSE is preserved as [CPython-3.12.10.txt](../../docs/licenses/CPython-3.12.10.txt); the [Unicode notice](../../docs/licenses/Unicode-3.0.txt) is also retained.

## Derivation and resource

`extract.py` verifies the provenance hash and each source file's raw hash/length before extraction. Its parser accepts only the expected integer arrays and six-field records, verifies SHIFT=7 and the three required flag masks, and rejects unsupported expressions. It follows `index1[cp >> SHIFT]`, then `index2[(index << SHIFT) + lowBits]` to the type record. Ordinary lowercase values are signed deltas; extended lowercase uses the low 16 bits as an index and the high byte as the sequence length. No casefold bits are used. Cased is flag `0x2000`, Case_Ignorable is `0x1000`.

The extractor visits exactly **1,112,064 valid Unicode scalars**, excluding surrogates. It validates all indices, mapping lengths, output scalars and the pinned C-table dimensions. Nonidentity mappings are stored as sorted `[scalar, [mappedScalars...]]` records; properties become sorted merged inclusive ranges. Identity mappings are implicit. After extraction, every source, the provenance file and the extractor itself are rehashed before generated bytes can be returned or written.

The resource [lower-3.12.10.json](../../src/ComfySharp.Nodes/Resources/PythonUnicode/lower-3.12.10.json) is compact ASCII JSON with a final LF, **29026 bytes**, SHA-256 **`6381d72114b8aa4ee5c0dd04fcbb55395964ab1ca92832e7784f887dfbf8b42c`**. It records its source commit, provenance SHA and exact extractor SHA. Its contents are:

| Item | Count |
|---|---:|
| Type records / extended scalar pool | 504 / 1236 |
| First / second index arrays | 8704 / 36224 |
| Nonidentity lowercase mappings | 1433 |
| Expanding lowercase mappings | 1 (U+0130 → U+0069 U+0307) |
| Cased scalars / merged ranges | 4526 / 157 |
| Case_Ignorable scalars / merged ranges | 2707 / 437 |

The product validates the raw embedded resource hash before parsing, then validates schema, metadata, dimensions, unique sorted keys, scalar ranges and derived counts. Tables are immutable and initialized once. A new Unicode version requires new pinned source data and a reviewed resource; system/runtime globalization updates cannot silently change these mappings.

## Reproduction without source execution

Place the six exact files at their relative paths below an existing source directory. The extractor performs no downloads. With Python stdlib only:

```powershell
python -I -S -B labs/python-unicode-tables/extract.py --source-directory <original-files-directory> --check src/ComfySharp.Nodes/Resources/PythonUnicode/lower-3.12.10.json
```

Omitting `--check` prints only the generated byte hash and counts. `--output <absent-file>` creates a new file exclusively and refuses a destination under the source directory. It never overwrites an existing resource or original file. Both modes are static integer/data processing; they do not execute CPython's lowercase behavior.

## Product algorithm and limits

`PythonUnicodeLower.Lower` validates UTF-16, maps original scalars using the embedded full-lowercase data, and applies the source Final_Sigma condition. A capital sigma is final only when the previous non-Case_Ignorable scalar is Cased and the next non-Case_Ignorable scalar is absent or not Cased. **Case_Ignorable takes precedence when both bits are set**, notably U+0345. Context uses the original whole argument, never a normalized/mapped string or a prospective substring match.

The C# adaptation replaces repeated context searches with a backward pass recording following Cased status at sigma positions, then a forward pass tracking preceding status. At most one bit per input UTF-16 unit is allocated for context, only if a capital sigma is present. Processing is linear in input/output length with fixed-size table lookups; long combining runs do not create quadratic searches. Output uses checked .NET string-size accounting, not an arbitrary text quota. Allocation failure remains an ordinary runtime resource failure; it does not truncate or fabricate output.

The helper does not normalize NFC, trim, casefold, perform culture-sensitive comparison or call OS Unicode classification/casing. `ValidateUnicode` is available for case-sensitive node paths too. Both entry points reject isolated surrogates with an explicit `unsupported_unicode_value` message and preserve the cancellation token. Cancellation is checked before work, during decoding/context/mapping, and before return; immutable table initialization and individual bounded allocations are not instantaneously interruptible.

These tables establish static derivation provenance, not yet a runtime parity verdict. Managed known-example/structure/cancellation tests and the separately published independent builtin source corpus are distinct evidence. This generator must never be presented as an independent builtin oracle: it derives the product data directly from the pinned C arrays. The enclosing Contains/Compare nodes, HTTP and editor workflows require their own tests and qualification.
