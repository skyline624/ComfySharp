# JSON Python à l'import

La [CI des trois OS](qualification/import-ci-20260912.md) confirme les 46 nouveaux cas et le parcours natif au commit `1d67fb9`. Les échecs numériques indépendants restent documentés dans ce relevé.

L'ouverture d'un workflow ou d'un prompt API, depuis un fichier JSON ou les métadonnées d'un PNG, accepte désormais les tokens nus `NaN`, `Infinity` et `-Infinity`. Ils deviennent `null` et un avertissement est affiché. Les mots identiques à l'intérieur d'une chaîne, les clés et les séquences échappées restent inchangés.

Le comportement de référence est [`parseJsonWithNonFinite`](https://github.com/Comfy-Org/ComfyUI_frontend/blob/e7d1c7fc6823e330fdab524610b0000394cb1dbc/src/utils/jsonUtil.ts) : essai JSON strict, puis remplacement à l'import après échec, avec un avertissement par appel. Le port C# effectue un balayage linéaire des chaînes et tokens, sans expressions régulières ni exécution JavaScript. Le parseur JSON reste responsable de refuser toute autre syntaxe invalide. Les nombres représentés avec une syntaxe JSON valide, même de très grand exposant, ne passent pas par cette conversion.

La conversion perd l'information numérique non finie. L'éditeur n'assigne donc pas le fichier JSON original comme destination automatique de sauvegarde lorsqu'un avertissement de conversion a été émis. Il propose un nouveau workflow `.workflow.json`. Le PNG source reste également distinct de la sauvegarde. Le lecteur n'écrit jamais dans le flux fourni. Les champs inconnus conservent leur structure ; seules les valeurs non finies concernées sont remplacées.

Pour les PNG, le workflow graphique est essayé en premier. En cas d'erreur de syntaxe, de structure ou de version non prise en charge, un avertissement explique le repli vers le champ `prompt`. Si ce prompt est valide, il ouvre un document éditable. Sinon l'import échoue ; les onglets existants sont conservés. L'import A1111 reste explicitement indisponible. Cette priorité suit [`handleFile`](https://github.com/Comfy-Org/ComfyUI_frontend/blob/e7d1c7fc6823e330fdab524610b0000394cb1dbc/src/scripts/app.ts#L2025), dans les limites des formats actuellement portés.

Cette tolérance appartient à la frontière d'import. `WorkflowDocument.Parse`, les écritures JSON et les contrats HTTP du Host conservent leur comportement strict. Le callback `reportWarning` des lecteurs de bibliothèque permet à leurs appelants de recueillir les avertissements ; Desktop l'utilise pour les afficher. Un import réussi ne garantit pas que les valeurs `null` satisfassent les types exigés par les nœuds : la compilation et la validation du Host restent nécessaires.

La [campagne de vérification](qualification/nonfinite-import.json) couvre les tokens, chaînes/échappements, erreurs persistantes, avertissements, un tableau de 10 000 éléments, la priorité des métadonnées, le repli et les quatre combinaisons JSON/PNG × workflow/prompt dans l'éditeur. Le parcours natif vérifie la conversion et son avertissement avant d'éditer une valeur, de compiler et d'exécuter le prompt sur le Host séparé. Les cas sont des contrats .NET ; aucune exécution comparative du programme JavaScript ni fidélité universelle aux JSON malformés n'est revendiquée.
